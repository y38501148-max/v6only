# 新版本提示

2.1.11 起，Windows、macOS 和 Android 在应用启动或回到前台时检查 GitHub 稳定版；前台运行期间每 6 小时检查一次。可点击“检查更新”立即重试。自动检查失败不改变连接状态，至少等待 15 分钟后再尝试。

存在版本更高、已上传完成的当前平台安装包时，显示版本提示，并提供“下载新版”“更新说明”和“稍后”。同一版本关闭后不重复提示，手动检查可以重新显示。最新发布暂未提供当前设备安装包时会单独说明，不显示“已是最新版”。

此功能提供更新提示和下载入口，安装仍使用原平台安装流程。应用没有运行、Android 被强制停止或没有可用网络时，不保证及时提示。2.1.10 及更早版本需要先手动安装包含提示器的版本，才能收到后续提醒。

检查直接读取公开 GitHub Releases 元数据，按数字比较稳定版本，并核对资产名称、仓库下载路径、上传状态和大小。不会上传流量记录或查询历史；GitHub 作为请求接收方会看到常规连接信息。检查不依赖后台服务安装，不持有转发控制锁，不自动修改 IPv4 回退选择。

桌面应用与本机后台的版本不一致时，原有的“更新后台”入口继续保留，与云端应用更新分别处理。Android 保持原包名和签名才能覆盖升级；发布时统一所有版本字段和安装包版本。
