# V6Only desktop design

Native macOS network dashboard. Use a fixed navy navigation sidebar and a quiet light content surface. Use the system font for Chinese text and monospace only for IPs and logs.

Primary action #2459cd; IPv6 #087c74; IPv4 #bd651d; text #16243c; secondary text #53627a; surfaces #ffffff / #f4f6fa. Status must always include text and may use color as an additional indicator.

Use visible labels, keyboard focus rings, reduced-motion support, stable cards, no horizontal scrolling at the 820 × 620 minimum window size. Empty metrics use a dash and empty charts explicitly explain that no records exist. Never insert simulated metrics in the production application.

Use SVG icons consistently. Use 14 px body text with smaller supporting labels. Show upload/download separately, explicit time boundaries and exact units. All records stay local.
